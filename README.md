# 🛠️ Портал инструментов — каталог браузерных утилит

Каталог содержит **67 карточек**: 32 готовых инструмента работают локально в браузере, 2 карточки открывают отдельные проекты, ещё 33 функции отмечены «Скоро» и пока не являются готовыми конвертерами. Статусы не скрываются и не выдаются за уже реализованные функции.

## Новые инструменты

- **Ежедневная мастерская** — [открыть](https://ivanivorontsov-sudo.github.io/daily-tools/): 11 локальных инструментов для работы с текстом, файлами, изображениями и веб-адресами.

- **PDF Мастер** — [открыть](https://ivanivorontsov-sudo.github.io/pdf-master/): объединение PDF, сортировка, поворот, удаление/извлечение страниц, нумерация и очистка стандартных метаданных. Обработка выполняется в браузере.
- **ZIP-архивы** — создание архива из нескольких файлов и выборочное извлечение ZIP локально в браузере (JSZip 3.10.2, MIT).

## Программы для ПК

- **Иван Tools — пакеты Windows и Linux** — [описание, загрузчики и контроль SHA-256](desktop-bundles/README.md). В наборах нет VPN и прокси.

## Конфиденциальность и исходный код

Обработка поддерживаемых файлов выполняется в браузере. ZIP-инструменты используют локальную копию JSZip 3.10.2; библиотека и лицензия расположены в `assets/js/vendor/`. Генератор QR-кодов использует библиотеку, включённую в репозиторий: текст для QR-кода не отправляется на внешний QR-сервис. Страница загружает Tailwind CSS и Font Awesome с публичных CDN; поставщики этих CDN могут получать обычные технические сведения сетевых запросов. Подробности: [политика конфиденциальности](https://ivanivorontsov-sudo.github.io/tools-portal/privacy.html).

Код, написанный для самого портала, распространяется по MIT License из корня репозитория. Включённые сторонние библиотеки имеют собственные лицензии и уведомления в `assets/js/vendor/`; MIT-файл корня не заменяет их условия. Для внешних программ и скачиваемых сборок действуют лицензии соответствующих проектов. Исходный код открыт для просмотра и проверки: [репозиторий GitHub](https://github.com/ivanivorontsov-sudo/tools-portal).

## Возможности

- 🖼️ **Конвертеры изображений** — JPG ↔ PNG ↔ WEBP ↔ SVG ↔ HEIC и др.
- 🎬 **Видео** — MP4, MOV, MKV, WebM, AVI, GIF и извлечение аудио
- 🎵 **Аудио** — MP3, WAV, FLAC, AAC, OGG, M4A
- 📄 **Документы** — PDF, DOCX, TXT, Markdown, CSV ↔ JSON
- 🧰 **Утилиты** — сжатие изображений, QR-коды, генератор паролей, Base64, JSON-форматтер, хеши, конвертер единиц и многое другое

## Технологии

- Чистый HTML + локально собранный Tailwind CSS 3.4.19 (Play CDN не используется в production)
- Vanilla JavaScript (SPA с hash-routing)
- Клиентская обработка где возможно (Canvas API, FileReader)
- Адаптивный дизайн, тёмная/светлая тема

## Запуск локально

Просто откройте index.html в браузере или используйте любой статический сервер:

~~~bash
npx serve .
~~~
