# 🛠️ Tools Portal — 60+ онлайн-конвертеров и полезных инструментов

Современный веб-портал с **более чем 50** бесплатными онлайн-инструментами для конвертации файлов и повседневных задач.

## Новые инструменты

- **Ежедневная мастерская** — [открыть](https://ivanivorontsov-sudo.github.io/daily-tools/): 11 локальных инструментов для работы с текстом, файлами, изображениями и веб-адресами.

- **PDF Мастер** — [открыть](https://ivanivorontsov-sudo.github.io/pdf-master/): объединение PDF, сортировка, поворот, удаление/извлечение страниц, нумерация и очистка стандартных метаданных. Обработка выполняется в браузере.

## Программы для ПК

- **Иван Tools — пакеты Windows и Linux** — [описание, загрузчики и контроль SHA-256](desktop-bundles/README.md). В наборах нет VPN и прокси.

## Возможности

- 🖼️ **Конвертеры изображений** — JPG ↔ PNG ↔ WEBP ↔ SVG ↔ HEIC и др.
- 🎬 **Видео** — MP4, MOV, MKV, WebM, AVI, GIF и извлечение аудио
- 🎵 **Аудио** — MP3, WAV, FLAC, AAC, OGG, M4A
- 📄 **Документы** — PDF, DOCX, TXT, Markdown, CSV ↔ JSON
- 🧰 **Утилиты** — сжатие изображений, QR-коды, генератор паролей, Base64, JSON-форматтер, хеши, unit converter и многое другое

## Технологии

- Чистый HTML + Tailwind CSS (CDN)
- Vanilla JavaScript (SPA с hash-routing)
- Клиентская обработка где возможно (Canvas API, FileReader)
- Адаптивный дизайн, тёмная/светлая тема

## Запуск локально

Просто откройте index.html в браузере или используйте любой статический сервер:

~~~bash
npx serve .
~~~
