# PDF Мастер

**Веб-инструмент для работы со страницами PDF без регистрации, рекламы и подписки.**

Открыть: https://ivanivorontsov-sudo.github.io/tools-portal/pdf-master/

## Возможности

- Добавление нескольких PDF за один раз.
- Предпросмотр страниц.
- Объединение выбранных страниц из разных документов в один PDF.
- Изменение порядка страниц перетаскиванием.
- Поворот страницы на 90°.
- Удаление страниц из итогового рабочего списка.
- Выбор отдельных страниц и диапазонов (например, `1-3, 5, 8-10`).
- Нумерация страниц итогового файла.
- Очистка стандартных полей метаданных PDF и XMP-пакета, если он доступен.

## Приватность и обработка

Байты PDF читаются локально через File API и обрабатываются в браузере с помощью PDF.js и pdf-lib. Содержимое PDF не отправляется на сервер сайта или CDN. Оригинальные файлы не изменяются; создаётся новый PDF.

Для загрузки библиотек страница обращается к публичным CDN:
- PDF.js 3.11.174 (Apache-2.0);
- pdf-lib 1.17.1 (MIT).

CDN получает технические сведения об обычном запросе на загрузку библиотеки (например, IP-адрес, время запроса и параметры браузера), но не получает выбранные пользователем PDF-файлы. GitHub Pages отдельно обрабатывает технические запросы к хостингу.

Настройка цветовой темы хранится в localStorage браузера. Учётных записей, аналитики, рекламы, форм загрузки на сервер и платных функций в инструменте нет.

Подробности: [политика конфиденциальности](privacy.html).

## Ограничения

- Зашифрованные/защищённые паролем PDF не поддерживаются.
- Изменение или сохранение PDF делает существующие цифровые подписи недействительными.
- Интерактивные формы, закладки, вложения, некоторые аннотации и сложные функции PDF могут не сохраниться при создании нового документа.
- Очистка удаляет стандартные поля документа и XMP-метаданные, если они доступны. Она не является инструментом редактирования/замазывания содержимого страниц и не удаляет скрытый текст, историю изменений, комментарии или данные внутри самих страниц.
- Большие документы могут требовать значительный объём оперативной памяти браузера.
