Политика конфиденциальности

Портал инструментов · Обновлено: 16 ноября 2026 года

Главное. Поддерживаемые локальные инструменты читают выбранные файлы и введённые данные средствами браузера. В коде этого репозитория не предусмотрена отправка таких файлов или содержимого полей на сервер автора. Это не означает, что сайт вообще не выполняет сетевых запросов: хостинг и внешние CDN получают технические сведения обычных HTTP-запросов, а исполняемые сторонние скрипты являются отдельной границей доверия.

1. Что происходит с файлами и текстом

Для активных браузерных инструментов файлы читаются через File API, а преобразования выполняются на устройстве пользователя с помощью JavaScript и возможностей браузера. ZIP-инструменты используют локально включённую библиотеку JSZip 3.10.2; её лицензионный текст находится в assets/js/vendor/JSZIP-LICENSE.txt. Генератор QR-кодов использует включённую в репозиторий библиотеку, поэтому текст QR-кода не передаётся отдельному QR-сервису.

Инструменты, помеченные в каталоге как «Скоро», ещё не реализованы как готовые конвертеры. Внешние проекты, открываемые по ссылкам (например, PDF Мастер и Ежедневная мастерская), имеют собственные страницы и описания обработки данных.

Портал не содержит формы загрузки пользовательских файлов на сервер автора, личных кабинетов или собственной рекламной аналитики. Это описание относится к коду репозитория и не распространяется автоматически на сторонние сайты, на которые пользователь переходит по ссылкам.

2. Локальное хранение

Текущие рабочие файлы и результаты находятся в памяти вкладки до завершения операции или закрытия/перезагрузки страницы. Выбранная тема оформления может храниться в localStorage браузера. В коде портала эта настройка не содержит содержимое файлов или введённый текст и не передаётся автору.

Отдельно о странице «Генератор отмазок». Скрипт funny-generators/app.js формирует варианты ответа непосредственно во вкладке браузера. Введённая строка используется только в оперативной памяти страницы; сайт не отправляет её на сервер, не записывает в cookie, localStorage или sessionStorage и не подключает для этой страницы сторонние библиотеки, счётчики, рекламные SDK или формы. Политика Content Security Policy для страницы запрещает сетевые соединения из её кода (connect-src 'none'). Копирование в буфер обмена и вызов системного меню «Поделиться» возможны только после отдельного нажатия пользователя; после этого данные обрабатываются выбранным браузером, операционной системой или приложением-получателем вне контроля автора сайта. Не вводите в поле реальные имена, телефоны, адреса и иные сведения, которые не нужны для шутки. Технические сведения HTTP-запроса при открытии страницы по-прежнему обрабатываются инфраструктурой GitHub Pages, как описано ниже.

3. Хостинг и внешние поставщики

Сайт размещён на GitHub Pages. GitHub самостоятельно обслуживает HTTP-запросы к хостингу и может обрабатывать технические данные, включая IP-адрес, время обращения, запрошенный ресурс и параметры браузера, по своим правилам. Автор проекта не имеет доступа к внутренним журналам GitHub Pages.

Стили Tailwind CSS 3.4.19 заранее собираются в локальный файл assets/css/tailwind.min.css; исполняемый Tailwind Play CDN на странице не используется. Это удаляет необходимость запускать внешний Tailwind JavaScript в контексте страницы. Для иконок загружается таблица стилей Font Awesome 6.7.2 с cdnjs.cloudflare.com; CSS закреплён атрибутом Subresource Integrity (SRI), поэтому браузер проверяет его контрольную сумму перед применением. Браузер также загружает связанные шрифты с CDN; SRI таблицы стилей не проверяет эти отдельные файлы шрифтов. CDN получает обычные технические сведения сетевых запросов (например, IP-адрес, время и запрошенный ресурс). В коде портала не обнаружена отправка содержимого полей или пользовательских файлов этому поставщику.

PDF Мастер загружает закреплённые версии PDF.js 6.5.438 и pdf-lib 1.17.1 с публичных CDN; для просмотра PDF используются также worker, шрифты, CMaps и WASM-ресурсы PDF.js. Выбранные документы передаются библиотекам для локальной обработки в памяти браузера, но не прикрепляются к запросам загрузки самих библиотек. Риск цепочки поставок сторонних CDN сохраняется.

Внешние поставщики могут получать технические данные сетевого соединения независимо от автора сайта. Ссылки и переход на внешний сервис означают отдельное взаимодействие пользователя с соответствующим поставщиком и подпадают под его документы о конфиденциальности.

4. Внешние коммуникации и платежи

В репозитории не обнаружены встроенные виджеты, SDK или автоматическая отправка сообщений в Facebook, Instagram либо иностранные мессенджеры. В репозитории также нет платёжного API и формы приёма банковских данных. Карточка поддержки содержит ссылку на раздел реквизитов главного сайта; перевод пользователь совершает отдельно в приложении или на сайте выбранного банка. Банк обрабатывает платёжные сведения по собственным правилам.

Переход по добровольной ссылке, отправка электронного письма или публикация сообщения в GitHub Issues/Comments — отдельные действия пользователя. Содержание такого обращения получает соответствующий адресат и платформа.

5. Персональные данные и правовая рамка

Отсутствие собственной формы загрузки и аналитики само по себе не доказывает, что владелец сайта никогда не является оператором персональных данных. По пункту 2 статьи 3 Федерального закона № 152-ФЗ оператором является лицо, которое самостоятельно или совместно с другими организует и (или) осуществляет обработку персональных данных и определяет её цели, состав данных и совершаемые с ними операции. Поэтому статус оценивается по реальным процессам и распределению ролей, а не только по наличию формы на сайте. Если владелец сайта определяет обработку персональных данных, нужно отдельно оценить правовое основание, цели и состав данных, политику и меры защиты, локализацию баз при сборе данных граждан РФ (часть 5 статьи 18), уведомление Роскомнадзора по статье 22 и трансграничную передачу. Уведомление об обработке обычно подаётся до её начала, кроме прямо установленных частью 2 статьи 22 исключений. Для трансграничной передачи действует отдельное уведомление по статье 12; с учётом изменений Федерального закона от 26.07.2026 № 265-ФЗ оператору также нужно заранее получить сведения о принимающей стороне и оценить условия защиты данных. Сам факт загрузки внешней таблицы стилей или шрифта ещё не равен передаче введённых пользователем персональных данных; при этом IP-адрес и сетевые метаданные могут обрабатываться инфраструктурными поставщиками по их собственным правилам.

Сам факт того, что сайт доступен из ЕС, не означает автоматического применения GDPR во всех случаях. Территориальные критерии статьи 3 Регламента (ЕС) 2016/679 оцениваются отдельно — в частности, по наличию учреждения в ЕС либо предложению товаров/услуг лицам в ЕС или мониторингу их поведения.

Нормативные источники: 152-ФЗ «О персональных данных», статья 22 — уведомление, статья 12 — трансграничная передача, статья 18 — локализация баз, статья 18.1 — публикация политики, статья 22 — уведомление, GDPR.
